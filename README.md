# Studio de Beleza 1996

Site institucional responsivo para o Studio de Beleza 1996 — Carol Tavares.

## Executar

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000`.

## Conteúdo e agendamento

- Os preços selecionáveis refletem a tabela fornecida no briefing.
- A estimativa calcula o total e o sinal de 50%; o botão monta uma mensagem de consulta para o WhatsApp informado nas referências: **(19) 98214-6739**.
- Procedimentos capilares aparecem como consulta, pois não foi fornecido preço.
- Fotos de demonstração carregam do Unsplash. Troque pelas fotos autorizadas do estúdio antes da publicação, se desejar usar o portfólio real.
- O código do `HelixRibbonHero` foi implementado neste projeto; o briefing não incluía o código-fonte original citado.

## Stack

Next.js App Router, React, TypeScript, Tailwind CSS v4, GSAP + ScrollTrigger, Framer Motion, Lucide React e configuração shadcn/ui (`components.json`).
